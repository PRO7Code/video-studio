# Anan × Fluent — Thursday Weekly Reel (Remotion)

Vertical 1080×1920 · 30fps · ~39s · H.264 MP4 → `out/anan-thursday-reel.mp4`

```bash
npm i
npx remotion studio          # preview / edit
npx remotion render AnanReel out/anan-thursday-reel.mp4 --codec=h264 --crf=16 --audio-bitrate=320k
```

## Structure
- `src/timeline.ts` – scene lengths (frames) and transition length; everything derives from here.
- `src/scenes/*` – one file per scene (Hook, Title, Ideas, Slide, Mentor, Discussion, Tech, Outro).
- `src/components/Clip.tsx` – real-footage player: push-in zoom, focus/crop, **speed-ramp segments**, grading.
- `src/components/Type.tsx` – RTL kinetic Arabic words (animated per word to keep ligatures intact), tech chips, "قيد التطوير" badge.
- `src/components/transitions.tsx` – custom zoom-blur transition.
- `public/clips` – the original clips, transcoded to H.264 (HEVC→H.264, one clip rotated upright, audio denoised/normalized).
- `public/audio/music.wav` – original music bed generated by `tools/compose_music.py` (no third-party licence needed).
- `public/fonts` – Readex Pro (Arabic), Space Grotesk (Latin), JetBrains Mono — bundled locally (OFL).

## Notes
- Speech in the clips is distant/unintelligible (Whisper only produced low-confidence hallucinations), so **no subtitles were invented**; the on-screen text is editorial titling. Room sound is kept underneath.
- The architecture diagram is a schematic of the stated stack, not a screenshot of the actual product.

## Sound design (SFX)
- `src/sfx.ts` – cue sheet: each effect is placed on the exact frame of its visual event (transitions, chips, nodes, typing).
- `public/sfx/*.wav` – procedurally generated with `tools/make_sfx.py` (whooshes, pops, ticks, sub hit, scan glide, 4 key clicks). Original, no licence needed.
- Change a level or timing in `src/sfx.ts`; swap a sound by replacing the WAV with the same name.
- `out/anan-thursday-reel-no-sfx.mp4` – previous version without SFX.

## Media (not in git)
Private footage and the generated music bed are kept out of the repository.
To re-render: put the five normalised clips in `public/clips/` (hall-pan, hall-portrait, hall-wide, presenter,
room-establish – H.264 conversions of the original iPhone MOVs, see `docs/` ingest notes), regenerate the music with
`python tools/compose_music.py public/audio/music.wav`, then `npm i && npx remotion render AnanReel out/anan-thursday-reel.mp4`.
Delivered version: `anan-thursday-reel.mp4` (with SFX, hook = student presenting at the screen) and
`anan-thursday-reel-no-sfx.mp4`. Do not modify the delivered cut; new edits get a new filename.
